# Cosmic Daily Horoscope Website

Features included:
- Daily, weekly, monthly, and yearly horoscope
- All 12 zodiac signs
- Love compatibility
- Lucky numbers and lucky color
- Career, finance, health, and wellness predictions
- Chinese zodiac calculator
- Tarot card reading
- Birth chart-style inputs
- Share to Facebook, LinkedIn, X, TikTok, and Instagram
- Copy link button
- Email newsletter UI
- Mobile-friendly responsive design
- SEO meta tags
- Schema.org structured data
- PWA manifest
- Service worker
- AdSense placeholder areas
- Google Analytics placeholder

How to publish:
1. Upload this folder to Netlify, Vercel, or GitHub Pages.
2. Make sure index.html is in the root folder.
3. Apply for Google AdSense after the site is live and has enough useful content.
4. Replace the ad placeholder boxes with your AdSense code after approval.
